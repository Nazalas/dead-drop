How it works

    

      

        
🔢

        

          LSB Steganography
          
Every pixel has R, G, B, and Alpha values (0–255). We replace the 1–4 least significant bits of each channel — changes invisible to the human eye but enough to hide kilobytes of data.

        

      

      

        
🔐

        

          AES-256-GCM Encryption
          
Optional passphrase encrypts your message before it's hidden. Uses PBKDF2 (100k iterations) for key derivation — the hidden bytes are indistinguishable from noise even if someone knows to look.

        

      

      

        
🌊

        

          Alpha channel hiding
          
Most tools only think about RGB. Hiding data in the Alpha channel is particularly covert — it affects transparency, which is rarely inspected. Perfect for PNG images.

        

      

      

        
⚠️

        

          Use PNG, not JPEG
          
JPEG compression is lossy — it destroys the precise LSB values we embed. Always download and share as PNG to preserve the hidden data intact.
